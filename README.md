# Documentation

A simple personal project built to display GitHub profile README information in a more visual, organized, and responsive way across different devices.

The idea is to make existing profile information easier to explore and read, while keeping the content from the original README.

## GitHub API

The project uses the following public GitHub endpoints:

- **Users API:** `https://api.github.com/users/larissealves`
- **Social Accounts API:** `https://api.github.com/users/larissealves/social_accounts`
- **README API:** `https://api.github.com/repos/larissealves/larissealves/readme`

## Technologies

HTML, CSS, JavaScript, GitHub REST API, Marked.js and DOMPurify.

### Typography

The project uses three Google Fonts, each with a specific role in the visual hierarchy.

| Font | Usage |
|---|---|
| **Space Grotesk** | Display font for headings, titles, and card highlights. |
| **DM Sans** | Primary font for body text, descriptions, and interface elements. |
| **DM Mono** | Monospaced font for labels, metadata, and technical details. |

### Design Direction

- **Aesthetic:** Y2K-inspired, playful, and maximalist.
- **Visual elements:** Pink and lavender cards, decorative stars, stickers, rounded corners, and strong shadows.
- **Typography hierarchy:** Space Grotesk for visual impact, DM Sans for readability, and DM Mono for technical details.
- **Overall feeling:** A balance between a personal portfolio and a playful digital scrapbook.
